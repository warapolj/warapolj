## 👋 About me

I build software end to end — mostly TypeScript, across web, mobile and the
infrastructure underneath. Most of my work lives in private repos, so the stack
below says more about me than my public commits do.

These days I lead engineering at **[Day 1 Solution](https://day1solution.tech/)**,
building custom web, mobile and AI systems for businesses.

- 🧩 **Web** — Next.js / Astro on the front, NestJS / Hono on the API, PostgreSQL underneath
- 📱 **Mobile** — Flutter and React Native, through to release on the App Store and Google Play
- 🤖 **AI** — LLM-backed features and workflow automation
- 🚀 **Delivery** — I take work all the way to production, infrastructure and deployment included
- 💬 **Consulting** — architecture reviews, stack decisions and engineering practices
